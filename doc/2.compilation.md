# Compilation

IKVM11 includes two methods by which to compile Java byte code into .NET code: dynamic and static. Dynamic compilation happens at runtime when Java code loads Java class files, for instance using a `URLClassLoader` to load a JAR file. Static compilation happens before you run your .NET application. The Java SE 11 base classes included with IKVM11 are an example of static compilation.
